# Case Study: Grind

A game-style learning protocol that turns AI tutoring into replayable recordings.

## The Problem

As an MBA student, I had too much to learn and not enough time.

AI tutoring seemed like the answer — $20/month for unlimited PhD-level 1:1 sessions. But after weeks of using chatbots, I noticed a pattern:

- Every session started from zero
- I kept re-learning the same concepts
- Notes were scattered across dozens of conversations
- Nothing compounded

**The problem wasn't learning. It was retention.**

## The Solution

I built a learning protocol called "Grind" — named after the game mechanic of leveling up through repetition.

Core features:
- **Gym Map** — Visual progress tracker (badges, levels, current location)
- **P0/P1/P2 Priority System** — Learn concepts in order of importance
- **Breadcrumb Notes** — Record in YOUR words, not AI's words
- **REC Files** — "Recordings" you can replay later

The key insight: **learning is a journey, not a transaction**. The REC file is like a course recording — you can fast-forward, rewind, and review.
