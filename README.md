## The Solution: Grind Protocol

A protocol that gives AI learning the structure of a real course.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   🗺️  Learning Map     Your syllabus. Track where you are.             │
│                                                                         │
│   📊  P0/P1/P2         Priority system. Learn important things first.  │
│                                                                         │
│   🍞  Breadcrumbs      Notes in YOUR words, not AI's words.            │
│                                                                         │
│   🔴  REC Files        "Recordings" you can replay anytime.            │
│                                                                         │
│   🧠  Feynman Check    "Explain it back to me." Real understanding.    │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### Why It Sticks

```
Traditional notes:              This protocol:

• Concept A                        ┌─────────┐
• Concept B                        │   P0    │ Foundation
• Concept C                        └────┬────┘
                                        │ builds on
(flat list,                             ▼
 no connections)                   ┌─────────┐
                                   │   P1    │ Uses P0
                                   └────┬────┘
                                        │ builds on
                                        ▼
                                   ┌─────────┐
                                   │   P2    │ Uses P0 + P1
                                   └─────────┘

Concepts don't just exist — they CONNECT.
```

Three mechanisms make knowledge stick:

| Mechanism | How it works |
|-----------|--------------|
| **Layered concepts** | P0 → P1 → P2, each building on the last |
| **Your words captured** | Breadcrumbs record YOUR metaphors, not AI's explanations |
| **Follow-up depth** | Questions keep going until you actually understand |

### What It Looks Like

**Without this protocol:**

```
┌─────────────────────────────────────┐
│  You: "Explain X to me"             │
│  AI:  [long explanation]            │
│  You: "What about Y?"               │
│  AI:  [another explanation]         │
│  You: "Thanks!"                     │
│                                     │
│  [Close window]                     │
│                                     │
│          ↓                          │
│                                     │
│     Nothing remains.                │
│     Next week: "Wait, what was X?"  │
└─────────────────────────────────────┘
```

**With this protocol:**

```
┌─────────────────────────────────────┐      ┌─────────────────────────────────────────┐
│  [Learning conversation]            │      │  REC-topic-name.md                      │
│                                     │      │                                         │
│  AI: "Let me teach you X..."        │      │  🗺️ Progress: Part 2 of 4               │
│  AI: "Feynman Check: explain X      │      │  ████████░░░░░░░░ 50%                   │
│       back to me in your words"     │  ──► │                                         │
│  You: "So X is like... [your words]"│      │  📊 Visual Notes:                       │
│  AI: "Good! Now let's build on it..." │    │  ┌─────────┐    ┌─────────┐             │
│                                     │      │  │ Input A │───►│ Output  │             │
│  [Session ends]                     │      │  └─────────┘    └─────────┘             │
│                                     │      │                                         │
└─────────────────────────────────────┘      │  🍞 Breadcrumb:                         │
                                             │  - Quiz: Why does X work this way?      │
                                             │  - Your answer: "Because..."            │
                                             │  - Insight: The key is separation       │
                                             │                                         │
                                             │  ✅ Feynman Check: passed               │
                                             └─────────────────────────────────────────┘
                                                           │
                                                           ▼
                                              You can replay this anytime.
                                              Next session starts HERE, not from zero.
```

**What you get when you finish a course:**

A "recording-level" markdown document containing:
- Visual diagrams that explain concepts (not AI's words, actual visuals)
- Your own answers to quiz questions (proof you understood, not just read)
- Insights you discovered along the way (connections only YOU made)

**The result**: Every learning session leaves behind a "recording" you can return to.

This is what "Visual Notes" means: concepts become diagrams you can replay.

## How I Built This: The Friction Flywheel

Here's the meta part.

I didn't design this protocol in one sitting. I **built it while using it**.

```
                    ╭──────────────────╮
                    │                  │
                    ▼                  │
              ┌───────────┐            │
              │    USE    │            │
              └─────┬─────┘            │
                    │                  │
                    ▼                  │
              ┌───────────┐            │
              │ FRICTION  │  ← Most people stop here
              └─────┬─────┘            │
                    │                  │
                    ▼                  │
              ┌───────────┐            │
              │    LOG    │  ← I write down what felt wrong
              └─────┬─────┘            │
                    │                  │
                    ▼                  │
              ┌───────────┐            │
              │ FEED BACK │  ← I update the protocol
              └─────┬─────┘            │
                    │                  │
                    ▼                  │
              ┌───────────┐            │
              │  IMPROVE  │────────────╯
              └───────────┘
```

**Result**: v1 → v4.1 in 4 days.

| Version | What Felt Wrong | What I Changed |
|---------|-----------------|----------------|
| v1→v2 | "This is overwhelming" | One concept at a time, visual progress |
| v2→v3 | "Prerequisites are just labels, not helpful" | Rich explanations for each prereq |
| v3→v4 | "I can guess the right answer without understanding" | Open-ended Feynman Checks |
| v4→v4.1 | "ASCII art breaks in markdown preview" | Code block enforcement |

**Each friction point became fuel for the next version.**

## Philosophy

```
╔═══════════════════════════════════════════════════════════════╗
║                                                               ║
║                  THE OBSTACLE IS THE WAY.                     ║
║                                                               ║
╚═══════════════════════════════════════════════════════════════╝
```

This entire system exists because of friction, not despite it.

```
v1 was bad ──────► friction ──────► v2
v2 had gaps ─────► friction ──────► v3
v3 allowed fake understanding ───► friction ──────► v4
```

**Friction is not failure. It's signal.**

Most people hit friction and complain. This system treats friction as data: log it, feed it back, improve.

Version control is your safety net. If you break something, rollback. This removes fear from iteration.
